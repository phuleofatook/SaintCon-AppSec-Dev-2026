# Repository guidance

## Folder structure

- `src/` is the main application source folder and the primary place to make code changes.
- `excersizes/` contains exercise material. Do not inspect, evaluate, or modify its contents unless the task explicitly concerns the exercises.  These exercises may be intentionally buggy or unsecure.
- `raw assets/` contains project assets.
- `dist/` contains build output; treat it as generated output rather than a source folder.

When a task does not mention exercises, focus work on `src/` and the relevant project-level configuration or documentation.
